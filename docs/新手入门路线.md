# 币圈新手入门路线

刚接触币圈不用一下子研究太多东西，先把最基础的一套流程走通：

> 注册交易所 → 完成 KYC → 小额入金 → 购买 USDT → 现货交易 → 提币到钱包 → 学习链上操作

第一次不要放太多钱，也不要着急碰合约。先用小额资金完整操作一遍，知道钱怎么进、怎么买币、怎么转出去，比一开始研究各种“百倍币”重要得多。

## 1. 注册交易所

新手先选择常用的大交易所，注册入口可以看项目首页的[中心化大所](../README.md#中心化大所)。下载 App 时要认准官网，不要点搜索广告，也不要使用群里陌生人发来的安装包。

注册完成后，先把这些安全设置打开：

- 设置一个没有在其他网站用过的密码；
- 开启谷歌验证器等二次验证；
- 设置防钓鱼码，以后收到邮件时可以用来辨别真假；
- 验证码、密码和备份码不要发给任何人，客服也不会向你索要这些信息。

## 2. 完成 KYC

KYC 就是实名认证，一般需要上传身份证件并进行人脸识别。完成以后才能正常使用 C2C、充币、买币和提币等功能。

认证时一定要确认自己用的是官方 App 或网站，不要让别人远程控制手机，也不要找人“代过 KYC”。不同地区可以使用的功能可能不一样，以交易所页面实际显示为准。

## 3. 小额入金，先买一点 USDT

USDT 也就是大家常说的“U”，可以理解为币圈里最常用的美元计价稳定币。新手通常会通过 C2C 用人民币购买 USDT，然后再用 USDT 买 BTC、ETH 等其他币。

C2C 交易时注意：

- 全程在交易所订单里操作，不要脱离平台私下交易；
- 按订单显示的信息付款，不要相信商家私聊发来的新账号；
- 付款后不要随意取消订单，有问题就申请平台客服介入；
- 第一次只买一小笔，先熟悉整个流程。

具体步骤可以参考：[OKX C2C 人民币入金详细教程](./欧易c2c微信支付宝银行卡入金详细步骤.md)。

## 4. 先玩现货，不要急着碰合约

现货就是直接买币。例如用 100 USDT 买入 BTC，买完以后账户里会有对应数量的 BTC。价格跌了会亏钱，但币还在账户里。

合约主要是判断价格涨跌，通常还会使用杠杆。杠杆会同时放大收益和亏损，一次不大的反向波动就可能爆仓，本金也可能全部亏掉。

新手先从小额现货开始，弄明白市价单、限价单和手续费以后，再学习其他交易方式。看到“稳赚”“带单”“老师喊单”之类的信息，直接提高警惕。

## 5. 分清 C2C、充值、提现和划转

这几个词经常出现，刚开始很容易搞混：

- **C2C**：用人民币等法币向商家购买 USDT，或者把 USDT 卖给商家。
- **充值/充币**：把其他交易所或钱包里的币转进当前交易所。
- **提现/提币**：把交易所里的币转到其他交易所或自己的钱包。
- **链上转账**：通过区块链把币从一个地址发送到另一个地址，一般需要手续费。
- **资金划转**：在同一家交易所的资金账户、交易账户等账户之间移动，通常不上链。

简单来说，C2C 是人民币和币之间的买卖；充币、提币是真正把币转进转出；资金划转只是在交易所内部换一个账户。

## 6. 转账网络一定要选对

提币时经常会看到 ERC-20、TRC-20、BEP-20 等选项，它们代表不同的网络：

- **ERC-20**：以太坊网络，使用范围广，但网络繁忙时手续费可能比较高；
- **TRC-20**：波场网络，经常用于 USDT 转账；
- **BEP-20**：BNB Smart Chain，链上操作需要 BNB 作为手续费；
- **Arbitrum One**：以太坊 Layer 2，手续费通常比以太坊主网低；
- **Solana**：速度比较快，钱包里需要留一点 SOL 支付手续费。

转账时，发送方和接收方选择的网络必须完全一致。比如对方给你的是 TRC-20 充值地址，你在提币时也必须选择 TRC-20，不能因为 ERC-20 或 BEP-20 看起来差不多就随便选。

有些币充值时还需要填写 Memo 或 Tag，这个也不能漏。拿不准的时候先不要转，去接收平台的充值页面重新确认。

## 7. 为什么第一次一定要小额测试

链上转账发出去以后通常不能撤回。地址填错、网络选错或者 Memo 漏填，都可能导致资产无法到账。

正确做法是：

1. 在接收平台复制充值地址，确认币种和网络；
2. 核对地址开头和结尾的字符；
3. 先转一笔满足最低充值金额的小额资产；
4. 等小额到账后，再转剩余资金。

这样会多付一次手续费，但比一次把全部资金转错划算得多。即使是自己经常使用的地址，大额转账前也建议重新核对。

## 8. 学习使用自己的钱包

熟悉交易所操作以后，可以再学习 MetaMask、TokenPocket、imToken 等钱包。交易所账户由平台管理，自己的钱包则由助记词和私钥控制。

谁拿到助记词，谁就能控制钱包里的资产，所以要记住：

- 助记词只离线抄写，不截图、不上传网盘；
- 至少准备两份备份，放在不同且安全的位置；
- 不在任何网站输入助记词，恢复钱包时也要先确认软件来源；
- 所谓“客服”“项目方”向你索要助记词，基本可以直接判断是骗子；
- 钱包里要留一点对应公链的原生币，用来支付 Gas 手续费。

## 9. 再慢慢学习链上操作

完成一次小额提币后，可以继续学习用区块浏览器查交易、连接 DApp、兑换代币以及取消钱包授权。

每次连接钱包前先确认网址；看不懂的签名不要点确认；新项目和空投先用没有大额资产的小钱包操作。链上没有传统银行的撤销和找回机制，所以宁可慢一点，也不要闭着眼睛点下一步。

## 操作前再检查一遍

- 官网和 App 是不是真的？
- 发送和接收网络是否一致？
- 地址有没有复制错？
- 是否需要 Memo 或 Tag？
- 是否先转了一笔小额测试？
- 助记词有没有妥善保存？
- 这笔钱如果亏掉，会不会影响正常生活？

有一项不确定，就先停下来查清楚。币圈机会一直都有，资金安全永远比抢快几分钟重要。
